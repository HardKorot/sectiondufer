IWA JUSTICE V2

NOUVEAUTÉS
- Fiche complète par dossier
- Responsable du dossier
- Date d'audience
- Décision judiciaire
- Sanction / peine
- Notes internes réservées aux admins
- Archivage des affaires terminées
- Recherche et filtres actifs / archives
- Suppression définitive avec suppression automatique des notes
- Authentification admin Supabase conservée

INSTALLATION
1. Décompresse le ZIP.
2. Va dans Supabase > SQL Editor.
3. Ouvre le fichier migration-v2.sql.
4. Copie tout le contenu.
5. Clique sur Run.
6. Remplace les anciens fichiers du site par ceux de ce dossier.
7. Connecte-toi via login.html.

IMPORTANT
Ton compte admin actuel continue de fonctionner tant qu'il possède déjà :
app_metadata.role = admin

La table notes_plainte est totalement privée :
seuls les admins authentifiés peuvent la lire, écrire ou supprimer.

CONSEIL
Pour la mise en ligne, héberge tous les fichiers ensemble sur GitHub Pages, Netlify ou autre hébergement statique.
