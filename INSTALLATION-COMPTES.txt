IWA - IDENTIFIANT + MOT DE PASSE

1. Mets les fichiers du ZIP sur GitHub.
2. Dans Supabase : Edge Functions > Deploy a new function > Via Editor.
3. Nom : create-iwa-user
4. Colle le contenu de supabase-edge-function-create-iwa-user/index.ts
5. Deploy function.
6. Connecte-toi une dernière fois avec ton ancien compte e-mail (la page l'accepte encore).
7. Dans l'admin clique sur Comptes.
8. Crée ton premier identifiant + mot de passe.
9. Déconnecte-toi, puis reconnecte-toi uniquement avec cet identifiant.

Le service_role reste uniquement dans la Edge Function côté serveur et n'est jamais mis sur GitHub.
